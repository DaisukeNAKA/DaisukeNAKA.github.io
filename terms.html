アプリ概要 プライバシーポリシー 利用規約

本規約は、内部運用ツール「ユニコ短尺動画運用ツール」（以下「本アプリ」）の利用条件を定めます。本アプリはユニコ公式YouTubeチャンネルUCuwkUkClDI-EX_RO5p-O29A（@yy_unico）専用であり、一般向けサービスではありません。本アプリを利用することにより、利用者は本規約と適用されるYouTube利用規約に同意したものとします。

1. 利用資格

本アプリを利用できるのは、対象チャンネルの所有者および所有者が明示的に許可した運営担当者だけです。公開登録、第三者への再提供、複数テナント利用、第三者チャンネルへの投稿は認めません。

2. 提供機能と現在の制限

本アプリは、権利確認済みのローカル動画から作成したShortsについて、投稿先照合、private upload、メタデータ送信、重複防止、状態記録を行います。

YouTube API Compliance AuditとOAuth verificationは未完了です。そのため、公開予約と公開自動化は停止しています。private uploadの成功は公開運用の承認または完了を意味しません。

3. 運営担当者の責任

  • 動画、画像、音声、出演者、字幕その他の素材について、アップロードと公開に必要な権利・同意を確認すること。
  • 投稿前にtitle、description、privacy設定、対象チャンネル、公開日時を確認すること。
  • 子供向け設定、synthetic media申告、著作権、広告・表示義務を内容に応じて正しく判断すること。
  • OAuth credential、token、API key、パスワードを第三者へ開示しないこと。

4. 禁止事項

  • 権利のないコンテンツ、違法・有害・誤認を招くコンテンツの投稿
  • 視聴回数、高評価、コメント、登録者等の不正な操作
  • OAuth同意を超えるデータ利用、viewer profiling、API Dataの販売
  • quota回避のための複数project分割、認証先照合や安全ゲートの回避
  • YouTube Studioの無人ブラウザ操作、非公開APIや無許可の自動アクセス
  • 対象外チャンネルへの投稿または本アプリの第三者向け提供

5. Google／YouTubeサービス

本アプリはYouTube Data API v3とGoogle OAuthを使用します。本アプリを利用することで、利用者は適用されるYouTube利用規約に同意します。GoogleのポリシーおよびYouTube API Servicesの条件も適用されます。Google／YouTube側の停止、仕様変更、quota、審査結果により機能を停止または変更する場合があります。

6. データとプライバシー

データの種類、OAuth scopes、30日保持、第三者共有、認可失効、ローカル削除についてはプライバシーポリシーを適用します。

7. 認可失効・利用終了

運営担当者はGoogle Security Settingsからアクセス権を取り消せます。ローカルデータ削除はdaisuke.n0520@gmail.comへ依頼できます。安全上の問題、認可失効、規約違反、審査未完了がある場合、運営者は自動処理を停止します。

ローカルデータの削除は、YouTube上の動画を削除しません。YouTube上の動画はチャンネル所有者がYouTube Studio等で別途管理します。

8. 可用性と責任範囲

本アプリは内部運用を支援するもので、無停止稼働、公開時刻、再生数、エンゲージメント、審査通過を保証しません。運営担当者は送信結果とYouTube上の表示を確認し、結果不明時に重複投稿しないものとします。法令上免責できない責任は除きます。

9. 変更と問い合わせ

機能、適用規則、審査条件の変更に応じて本規約を更新します。重要な変更は運営担当者へ通知し、必要に応じて再同意を取得します。問い合わせ先はdaisuke.n0520@gmail.comです。
