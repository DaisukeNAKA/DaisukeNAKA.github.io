アプリについて

本アプリは、お笑いコンビ「ユニコ」が所有する単一の公式YouTubeチャンネルへ、権利確認済みのローカル動画から制作したShortsをアップロードし、運用するための内部ツールです。一般利用者の登録、第三者チャンネルへの投稿、コメント・高評価・チャンネル登録の自動操作は行いません。

Google OAuth権限

Google OAuth認可を開始またはYouTube API機能を使用する前に、運営担当者はプライバシーポリシーと利用規約を確認し、同意します。

youtube.upload

運営担当者が選択したShortsを対象チャンネルへアップロードし、承認されたタイトル、説明、公開設定を送るために使用します。監査完了前はprivateテストに限定します。

youtube.readonly

アップロード直前にchannels.list(mine=true)を実行し、認証中のチャンネルIDとhandleが固定の投稿先と一致するか確認するためだけに使用します。

より広いyoutube、youtube.force-ssl、YouTube Analytics等の権限は要求しません。

データ利用の概要

  • 動画ID、タイトル、説明、予約日時、投稿状態、エラー状態を内部台帳で扱います。
  • 公開済み動画のview／like／comment countをAPI keyで取得する場合、コメント本文や視聴者情報は取得せず、30日を超えた公開統計を自動削除します。
  • YouTube API Dataの販売、広告利用、無関係な第三者への共有は行いません。
  • 認可の失効とローカルデータ削除の現行手順はプライバシーポリシーに記載しています。

Googleによるデータの取扱いはGoogleプライバシーポリシーもご確認ください。

English summary

Unico Short-form Video Operations Tool is an internal tool for one creator-owned YouTube channel, UCuwkUkClDI-EX_RO5p-O29A (@yy_unico). It uses youtube.upload for operator-selected uploads and youtube.readonly only to verify the authenticated channel before writing.

The application is currently in internal testing. A historical private API upload test was completed with the retired v5 renderer, but the current v6 build has not completed its private proof or authorized person verification. Public scheduling and unattended publication remain disabled until those checks, the YouTube API Compliance Audit, and OAuth verification are complete. There is no public sign-up, third-party channel access, viewer profiling, comment-text collection, or sale of API Data.

Before starting Google OAuth or using YouTube API features, an operator must review and agree to the Privacy Policy and Terms of Use. Google's handling of data is described in the Google Privacy Policy.
