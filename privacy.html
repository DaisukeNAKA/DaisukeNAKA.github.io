本ポリシーは、内部運用ツール「ユニコ短尺動画運用ツール」（以下「本アプリ」）におけるGoogle／YouTube関連データの取扱いを説明します。本アプリの対象はユニコ公式YouTubeチャンネルUCuwkUkClDI-EX_RO5p-O29A（@yy_unico）だけです。利用者は、Google OAuth認可を開始しまたは本アプリのYouTube API機能を使用する前に、本ポリシーと利用規約を確認し、同意したうえで利用します。

現行状態：本アプリは内部テスト中です。退役済みv5のprivate uploadとmacOS Keychain保存は履歴上検証済みです。一括revoke／削除機能は実装・mock検証済みですが、Google実環境での解除証跡は未取得です。現行v6のprivate proof、権限ある運営者による人物確認、Compliance Audit、OAuth verificationが完了するまで、公開予約と無人公開を停止します。

1. 運営者と連絡先

本アプリはユニコ公式チャンネルの内部運営担当者が管理します。プライバシー、認可失効、データ削除に関する連絡先はdaisuke.n0520@gmail.comです。

3. OAuth scopesと利用目的

  • youtube.upload：運営担当者が確認した動画、title、description、privacy設定を対象チャンネルへ送信するため。
  • youtube.readonly：書込み直前に認証チャンネルを読み、固定チャンネル以外への誤投稿を停止するため。

本アプリはコメント、高評価、登録者、YouTube Analyticsの操作・取得に必要な追加scopeを要求しません。

4. 第三者共有

YouTube API Dataを販売、広告利用、プロファイリング、無関係な第三者への提供には使用しません。機能提供に必要なOAuthおよびYouTube Data API通信としてGoogle／YouTubeへ送信する場合を除き、YouTube laneから第三者へ共有しません。

Googleによるデータの取扱いについては、Googleプライバシーポリシーをご確認ください。

5. 保存期間

  • access token、認可code、stateは処理終了またはtimeout時に破棄します。
  • refresh tokenと認可済みAPI Dataは、内部運用に必要で認可が有効な期間だけ保持します。
  • 公開統計はNon-Authorized API Dataとして30日を超えて保持せず、収集時に期限超過行を削除します。
  • 削除依頼または認可失効を確認した場合、対象のローカルデータを可能な限り速やかに、遅くとも7暦日以内に削除します。

6. 認可の失効とローカルデータ削除

  1. Google Security Settingsから本アプリのアクセス権を取り消せます。
  2. ローカルに保存されたtokenとYouTube API Dataの削除は、daisuke.n0520@gmail.comへ依頼してください。メールにパスワードやtokenを記載しないでください。
  3. 運営者は新規API処理を停止し、対象のrefresh tokenと関連ローカルデータを可能な限り速やかに、遅くとも7暦日以内に削除します。

運営者はアプリの一括解除操作で、自動化停止、Google token revoke、Keychain token削除、現行台帳とアプリ管理下のバックアップSQLite／WALを含む関連ローカルAPI Data削除を開始できます。削除後は各台帳を再検査し、残存データを検出した場合は完了扱いにしません。

7. YouTube上の動画との区別

本アプリのローカルデータを削除しても、YouTube上の動画やYouTubeが保有するデータは削除されません。YouTube上の動画を削除する場合は、チャンネル所有者がYouTube Studio等のYouTube公式機能で別途管理します。

8. 改定

取扱データ、scope、利用目的が変わる場合は、本ポリシーとOAuth同意内容を更新し、必要な審査・再認可を行います。

English privacy summary

Before starting Google OAuth authorization or using this application's YouTube API features, an operator must review and agree to this policy and the Terms of Use. This internal application uses youtube.upload for operator-approved uploads and youtube.readonly only to verify the authenticated channel. It stores operational upload records locally and does not collect viewer identities, profiles, viewing history, or comment text.

Authorization codes, access tokens, and OAuth state are held only in process memory and discarded when the operation ends or times out. The refresh token is stored in macOS Keychain. An unresolved resumable upload session URL is retained locally only while it is needed to determine the upload outcome and is deleted after the outcome is confirmed or when access is disconnected. Disconnect also scrubs app-controlled backup SQLite databases and related WAL files, then verifies that no video ID, resumable session URL, private-test proof, or API metric remains. Public view, like, and comment counts are retrieved by API key, and records older than 30 days are deleted during collection.

YouTube API Data is not sold, used for advertising, or shared with unrelated third parties. Data sent to Google and YouTube is also governed by the Google Privacy Policy. Access can be revoked through Google Security Settings. Local deletion requests can be sent to daisuke.n0520@gmail.com. New API processing is stopped and the local refresh token and related local YouTube API Data are deleted as soon as practicable and no later than seven calendar days after a deletion request or confirmed authorization revocation.

Deleting local application data does not delete videos or data held by YouTube. YouTube-hosted videos must be managed separately through YouTube's official tools.
